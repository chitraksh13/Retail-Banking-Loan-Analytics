# 🏦 Retail Banking & Personal Loan Cross-Sell Analytics

An end-to-end data analytics portfolio project simulating a retail banking cross-sell campaign, utilizing SQL, Python, Advanced Excel, and Power BI.

## 📊 Project Overview
Financial institutions aim to maximize personal loan uptake while minimizing risk. This project analyzes a dataset of 5,000 retail bank customers to identify core conversion drivers, evaluate income brackets, and build an interactive executive dashboard for marketing segmentation.

## 🛠️ Tech Stack & Architecture
- **Database & SQL:** PostgreSQL (Data modeling, aggregation, customer segmentation queries)
- **Programming:** Python (`pandas`, `numpy`, `matplotlib` for EDA and summary stats)
- **Advanced Excel:** Dynamic amortization schedule, PMT financial modeling, and structured executive summary model (`Bank_Personal_Loan_Analytics_Model.xlsx`)
- **Dashboarding:** Power BI (`Retail_Banking_Loan_Cross_Sell_Dashboard.pbix`)

## 🔑 Key Findings & Insights
- **Income Impact:** Conversion rates spike dramatically among customers with annual incomes exceeding $100k.
- **Cross-Sell Opportunity:** High-income, high credit-card spenders ($3k+/month) who currently hold no personal loan represent prime targets for upcoming marketing campaigns.
- **Education Segments:** Advanced and professional degree holders exhibit significantly higher loan acceptance ratios.

## 📁 Repository Structure
- `/sql`: Contains PostgreSQL table schemas and analytical queries.
- `/python`: Contains Pandas data profiling and visualization scripts.
- `/excel`: Contains the financial model and amortization schedule workbook.
- `/powerbi`: Contains the `.pbix` interactive dashboard file.
